# Player advanced analytics

The Player Advanced tab uses precomputed 2025/26 supplemental player-match and profile tables. It presents totals, per-start, and per-90 values only when compatible minutes exist. WhoScored rating is descriptive and never affects Fantrax scoring. Observed tactical role remains separate from Fantrax eligibility, with manager and formation context shown as usage—not causation.

Match detail retains rating, manager, formation, role, Fantrax points/Ghost, Understat xG/xA, and audited event totals. Missing fields remain missing.
