# Fantrax supplemental statistics

Fantrax remains fantasy-scoring authority. A non-null Fantrax value—including explicit zero—always wins. WhoScored fills only genuinely missing exact player-match fields for three season-validated metrics: key passes, aerial wins, and interceptions. Each reconciled value retains `FANTRAX` or `WHOSCORED_SUPPLEMENT` provenance.

Clearances are caveat-only. Shots on target are not supplemented. WhoScored tackles remain distinct from Fantrax tackles won, and raw crosses remain distinct from Fantrax accurate crosses. Successful TakeOns remain WhoScored-specific because the exact historical layer lacks a season-scale Fantrax overlap field.
