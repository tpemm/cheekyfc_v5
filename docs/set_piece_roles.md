# Observed set-piece roles

Set-piece roles come from explicit WhoScored qualifiers. Production types are all corners, direct free-kick shots, indirect/short free kicks, penalties, set-piece key passes, and set-piece crosses. Shares and dense ranks are calculated within club, type, window, and observed manager regime; ties share rank.

Windows are Season, Last 10, Last 5, and Current Manager Regime. Every rank retains attempts, share, and club sample size. Corner coordinates form two clear groups (`y < 50`, `y >= 50`), but independent evidence does not establish which is human left versus right. Only `ALL_CORNERS` is therefore published.
