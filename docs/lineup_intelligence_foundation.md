# Lineup intelligence foundation

No predicted XI, start probability, or expected minutes is produced in Sprint 9.1. Current Fantrax weekly facts can support observed season/recent starts, appearances, minutes, minutes per appearance/start, consecutive starts, and bench patterns once periods complete.

`team_formation_history`, `team_lineup_history`, and `player_match_roles` are not registered because no authoritative current source is proven. Fantrax eligibility is never treated as actual tactical position. Sprint 9.2 should begin only after reproducible lineup/formation caches exist.
